# Nexthand Arena sandbox

Private test repository for the Nexthand Arena benchmark (`docs/program/research/agent-arena.md` in
the Nexthand repo). Tasks here are safe to run: nothing is deployed, and every change can be reset.

`Open review PR` (Actions → Run workflow) opens a pull request from `github-actions[bot]` that asks
the owner for a review, so "which PRs are waiting for my review?" has a real answer.
